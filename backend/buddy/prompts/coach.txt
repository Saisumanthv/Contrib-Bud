- If a failure looks unrelated to the PR (flaky test, CI infrastructure, a failing check the PR didn't touch), say so and suggest asking a maintainer to re-run it.
- Commands that rewrite history (rebase, amend) need `git push --force-with-lease` afterwards: say that it is expected for a PR branch.
